# Форматы файлов

Два формата: колода (в приложение) и прогресс (из приложения). Плюс резервная копия.

---

## 1. `anki-lite/deck` — колода

Что модель присылает ученику, а ученик вставляет во вкладку «Клод» → «Новые слова».

```json
{
  "format": "anki-lite/deck",
  "version": 1,
  "name": "work-meetings-1",
  "level": "B1",
  "source": "claude",
  "cards": [
    {
      "id": "w:bring-up",
      "front": "bring up",
      "back": "поднять (тему), упомянуть",
      "ipa": "/brɪŋ ʌp/",
      "pos": "phrasal verb",
      "level": "B1",
      "type": "word",
      "tags": ["phrasal-verbs", "work"],
      "examples": [
        { "en": "She brought up the budget question again.", "ru": "Она снова подняла вопрос бюджета." }
      ],
      "hint": "",
      "note": "bring up — поднять тему; bring back — вернуть"
    }
  ]
}
```

| Поле | Обяз. | Описание |
|---|---|---|
| `format` | да | всегда `anki-lite/deck` |
| `name` | нет | имя набора, попадает в список колод |
| `cards[].front` | **да** | английская сторона. Приложение считает её английской во всех режимах |
| `cards[].back` | да | русский перевод; несколько значений — через `;` |
| `cards[].id` | нет | если не задан, считается из `front` (`w:bring-up`). Повторный импорт с тем же `id` обновляет текст, **не сбрасывая прогресс** |
| `cards[].ipa` | нет | транскрипция, показывается под словом |
| `cards[].pos` | нет | часть речи, показывается как подсказка в режиме письма |
| `cards[].level` | нет | A1…C1 |
| `cards[].type` | нет | `word` (по умолчанию), `phrase`, `grammar`, `cloze` |
| `cards[].tags` | нет | 1–3 тега; по ним считается статистика слабых тем |
| `cards[].examples` | **да, хотя бы один** | `[{en, ru}]`; из первого примера приложение делает задание «вставь пропущенное слово» |
| `cards[].hint` | нет | подсказка перед показом ответа |
| `cards[].note` | нет | мнемоника, показывается вместе с ответом |

Синонимы полей, которые тоже понимаются: `en`/`term` вместо `front`, `ru`/`translation`
вместо `back`, `example` вместо `examples`, `phonetics` вместо `ipa`, `mnemonic` вместо `note`.

### Короткий текстовый формат

Для 3–5 слов JSON не нужен:

```
#phrasal-verbs work
bring up — поднять тему | She brought it up again. | Она снова подняла эту тему.
follow up — вернуться к вопросу позже
```

- разделитель сторон: ` — `, ` – `, ` - `, ` = `, `|` или табуляция;
- третье и четвёртое поля (через `|`) — пример и его перевод;
- строка с `#` задаёт теги для всех последующих строк;
- CSV/TSV тоже понимается: `front,back,example_en,example_ru,tags`.

## 2. `anki-lite/progress` — выгрузка прогресса

Что приложение отдаёт модели («Скачать файл»). Первое поле — инструкция для модели,
чтобы файл читался без всякого контекста.

```json
{
  "ИНСТРУКЦИЯ_ДЛЯ_МОДЕЛИ": { "что_это": "…", "что_сделать": ["…"], "шаблон_колоды": { } },
  "format": "anki-lite/progress",
  "version": 1,
  "exportedAt": "2026-07-30T21:00:00.000Z",
  "learner": { "name": "", "level": "B1", "goal": "" },
  "settings": { "newPerDay": 15, "reviewsPerDay": 120, "mode": "mixed" },
  "summary": {
    "totalCards": 120,
    "buckets": { "new": 20, "learning": 8, "relearn": 2, "young": 45, "mature": 45 },
    "reviewsTotal": 890, "reviews7d": 210, "reviews30d": 700,
    "accuracyAll": 0.81, "accuracy7d": 0.78, "accuracy30d": 0.8,
    "avgAnswerMs": 4200, "streakDays": 5, "studyDays": 21, "dueNow": 12
  },
  "byDay": [{ "date": "2026-07-30", "reviews": 42 }],
  "leeches": [
    { "id": "w:receive", "front": "receive", "back": "получать", "tags": ["verbs"],
      "reps": 9, "lapses": 5, "accuracy": 0.44, "state": "relearn", "interval": 1, "note": "" }
  ],
  "weakTags": [{ "tag": "phrasal-verbs", "reviews": 60, "cards": 18, "accuracy": 0.52 }],
  "typingErrors": [{ "id": "w:receive", "expected": "receive", "typed": "recieve", "verdict": "typo", "count": 3 }],
  "knownWell": ["take off", "give up"],
  "cards": [
    { "id": "w:receive", "front": "receive", "back": "получать", "tags": ["verbs"],
      "state": "relearn", "reps": 9, "lapses": 5, "ef": 1.9, "interval": 1,
      "due": "2026-07-31", "accuracy": 0.44,
      "history": [{ "ts": "2026-07-30T20:11Z", "g": 1, "mode": "typing", "ms": 7400, "typed": "recieve" }] }
  ]
}
```

Что важно знать при чтении:

- `g` в истории — оценка: `1` не помню, `2` тяжело, `3` помню, `4` легко.
  «Успех» = `g >= 3`, из этого считается `accuracy`.
- `mode` — в каком виде задавали: `recognition` (EN→RU), `typing` (писал по-английски),
  `listening` (на слух), `cloze` (вставлял в предложение).
- `state` — `new` / `learning` / `relearn` / `review`; `interval` в днях;
  «выучено» (`mature`) считается с 21 дня.
- `ef` — коэффициент лёгкости SM-2 (2.5 старт, ниже 2.0 — слово даётся тяжело).
- `history` обрезается до последних 8 ответов на карточку, чтобы файл не разрастался.
- Дневные счётчики и лимиты — в `settings`: если `buckets.new` большое, а `newPerDay` маленькое,
  ученик физически не успеет прожевать новую колоду.

### Короткая сводка

Кнопка «Скопировать сводку» кладёт в буфер тот же смысл в виде текста на 20–30 строк:
шапка с объяснением для модели, цифры, слабые темы, список «не идут», ошибки ввода,
список уже выученного и просьба прислать новую колоду. Для обычного разбора этого хватает,
файл нужен, когда хочется точности (история ответов, время, интервалы).

## 3. Резервная копия

Кнопка «Сохранить копию» отдаёт весь внутренний стейт: `cards` (с прогрессом),
`log` (все ответы), `settings`, `profile`, `daily`. Формата `format` в ней нет —
это чисто для восстановления в приложении, разбирать её модели не нужно.

Восстановление затирает текущие данные целиком.
