# Английский — карточки (аналог Anki + связка с Клодом)

Приложение для телефона: карточки с интервальным повторением, четыре режима тренировки,
озвучка, статистика. Работает **полностью офлайн** и никуда не отправляет данные.
Обмен с Клодом — вручную: приложение даёт сводку/файл, Клод отвечает колодой слов.

```
Клод ──колода JSON──▶ приложение ──учишь──▶ выгрузка прогресса ──▶ Клод ──разбор ошибок──▶ новая колода
```

## Что внутри

| Файл | Зачем |
|---|---|
| `app/` | само приложение (PWA: устанавливается на домашний экран, работает офлайн) |
| `dist/anki-lite.html` | то же самое одним файлом — можно открыть без хостинга |
| `decks/starter-en-a2-b1.json` | стартовая колода: 60 слов и выражений A2–B1 с примерами и транскрипцией |
| **`ДЛЯ-НЕЙРОНКИ.md`** | короткая инструкция для модели: что за файл пришёл и что с ним делать |
| **`CLAUDE_INSTRUCTIONS.md`** | полный регламент репетитора: цикл занятий, шаблоны ответов, команды |
| `PROFILE.md` | шаблон профиля ученика (модель заполняет и обновляет его сама) |
| `FORMATS.md` | точные схемы форматов `anki-lite/deck` и `anki-lite/progress` |

## Как поставить на Android

**Способ 1 — как приложение (рекомендую).** Нужен любой https-хостинг статики;
в репозитории лежит готовый workflow для GitHub Pages:

1. В настройках репозитория → Pages → Source выбери **GitHub Actions** (один раз).
2. Дождись, пока пройдёт workflow «Deploy app to Pages».
3. Открой полученный адрес (`https://<логин>.github.io/Anki/`) в Chrome на телефоне.
4. Меню Chrome (⋮) → **Установить приложение** / «Добавить на главный экран».

Дальше значок работает как обычное приложение: свой экран, без адресной строки, без интернета.

**Способ 2 — без хостинга.** Скачай `dist/anki-lite.html` на телефон и открой его в Chrome
(файл сам себе приложение: все стили, скрипты и стартовая колода внутри). Данные сохраняются,
но «установить на домашний экран» Chrome для локального файла не предложит.

**Способ 3 — если хочется именно APK.** Оберни ту же папку `app/` в WebView-контейнер
(Capacitor или Bubblewrap) на машине с Android Studio — здесь собрать APK нельзя,
в этом окружении нет Android SDK.

## Как заниматься

1. Вкладка **Клод** → «Загрузить стартовую колоду».
2. Вкладка **Учить** → выбери режим и жми «Учить». Оценивай себя честно: «не помню»
   вернёт слово через минуту, «легко» — через четыре дня.
3. Раз в несколько дней: вкладка **Клод** → «Скопировать сводку» → вставь в чат с Клодом.
   Он разберёт ошибки и пришлёт новую колоду — её текст вставляешь в поле «Новые слова».
4. Вкладка **Анализ** показывает то же самое локально: слабые темы, слова-камни,
   ошибки в написании.

Чтобы Клод сразу понимал, что от него нужно, дай ему один раз `CLAUDE_INSTRUCTIONS.md`
(лучше всего — в Project → Instructions на claude.ai). Файл выгрузки к тому же
самоописан: первым полем внутри JSON идёт инструкция для модели.

## Режимы тренировки

- **EN → RU** — узнавание: видишь слово, вспоминаешь перевод.
- **Писать по-английски** — активный словарь: видишь перевод, набираешь слово.
  Опечатка в одну букву не считается ошибкой, но записывается отдельно.
- **На слух** — слово озвучивается системным голосом, ты набираешь услышанное.
- **Пропуск в предложении** — вставляешь слово в живой пример.
- **Всё вперемешку** — приложение чередует режимы само (новое слово всегда сначала показывает).

## Алгоритм

SM-2 в духе Anki: этапы обучения 1 → 10 минут, затем интервалы растут на коэффициент
лёгкости (старт 2.5). Провал урезает интервал вдвое и отправляет слово на переучивание;
после 6 провалов слово помечается как проблемное и попадает в выгрузку отдельным списком.
Дневные лимиты (по умолчанию 15 новых и 120 повторений) не дают завалить себя.

## Разработка

```bash
node tools/build.mjs                 # генерирует app/js/starter.js и dist/anki-lite.html
node --test tests/*.test.js          # 45 тестов: алгоритм, парсер колод, выгрузка
http-server app -p 8123              # локальный запуск
node tests/smoke.mjs http://localhost:8123/   # 33 проверки в Chromium + скриншоты
python3 tools/make-icons.py          # перегенерировать иконки
```

Приложение — обычный HTML + JS без сборщиков и зависимостей. Логика повторений
(`app/js/srs.js`), разбор колод (`app/js/deck.js`) и выгрузка (`app/js/report.js`) —
чистые функции, они же и тестируются в node.
